# AI Test HTML Games

ブラウザで遊べるミニゲーム集です。`index.html` から各ゲームページへアクセスできます。

## 重要事項
このリポジトリに含まれるゲーム実装・仕様書・説明文の多くは**生成AIによって作成・更新されたコンテンツ**です。必要に応じて人手でのレビューと調整を行ってください。

## 収録ゲーム
- 数独（Sudoku）
- テトリス（Tetris）
- マインスイーパー（Minesweeper）
- ソリティア（Klondike）
- スターライト・バラージュ（Shooting）

## 構成
- `index.html`: ゲーム一覧ページ
- `games/*.html`: 各ゲーム本体
- `Specs/*.md`: 各ゲームの仕様書

## 使い方
1. このリポジトリをローカルに配置
2. `index.html` をブラウザで開く
3. 遊びたいゲームを選択

## ライセンス
必要に応じてプロジェクトポリシーに沿って追記してください。
