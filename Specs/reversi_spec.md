# リバーシ仕様書（CPU対戦・難易度5段階対応）

## 1. 目的
ブラウザ上で 1 人用リバーシ（オセロ）をプレイできるゲームを実装する。プレイヤーは CPU の強さを 5 段階（最弱 / 弱 / 中 / 強 / 最強）から選択でき、先攻・後攻も選択可能とする。

## 2. 対象環境
- 対応ブラウザ: 最新版 Chrome / Edge / Firefox（PC）
- 実行形態: 単一 HTML（必要に応じて CSS / JavaScript を同梱）
- 入力: マウス（必須）、キーボードは任意

## 3. ゲーム概要
- ゲーム種別: 標準リバーシ
- 盤面: 8 × 8
- 初期配置:
  - 4 マス中央に白黒 2 枚ずつを対角配置
  - 黒が先手、白が後手（ただしプレイヤーの先攻後攻選択に応じて人間側の色を決定）
- 勝敗条件: 全マス埋まる、または双方が連続パスした時点で石数が多い側の勝利

## 4. 画面仕様

### 4.1 タイトル / 設定エリア
- 難易度選択（ドロップダウンまたはラジオボタン）
  - 最弱
  - 弱
  - 中
  - 強
  - 最強
- 先攻後攻選択
  - プレイヤー先攻（黒）
  - プレイヤー後攻（白）
- 操作ボタン
  - `対局開始`
  - `リスタート`

### 4.2 盤面エリア
- 8 × 8 のグリッドを描画
- 各マスはクリック可能
- 石（黒 / 白）を視認可能に表示
- 着手可能マスのハイライト（ON/OFF切替は任意）

### 4.3 情報表示エリア
- 現在手番（プレイヤー / CPU）
- プレイヤー石数
- CPU石数
- 選択中難易度
- メッセージ表示
  - 不正手通知（置けないマスを選択した場合）
  - パス通知
  - 勝敗結果（勝ち / 負け / 引き分け）

## 5. ルール仕様

### 5.1 着手可能条件
- 空きマスであること
- 8 方向（上下左右斜め）いずれかで、相手石を 1 枚以上挟んで自石で閉じられること

### 5.2 反転処理
- 着手点から 8 方向を走査し、挟まれた相手石をすべて自石に反転
- 複数方向同時反転に対応

### 5.3 パス
- 手番プレイヤーに合法手が 1 つも無い場合、自動パス
- パス発生時は画面上で通知

### 5.4 終局条件
- 以下のいずれかで終局
  1. 盤面が 64 マスすべて埋まる
  2. プレイヤー・CPU が連続でパス
- 終局時に石数比較して結果表示

## 6. CPU 思考仕様（難易度別）

### 6.1 共通
- CPU は合法手のみ選択する
- 思考中は UI 上で「CPU思考中…」を表示（任意）
- 着手候補が複数同点の場合はランダム選択可

### 6.2 最弱
- 合法手から完全ランダムで選択
- 先読みなし

### 6.3 弱
- 1 手先のみ評価
- 評価関数: `即時反転枚数` を最大化
- 角・危険マスの概念は未考慮

### 6.4 中
- 1 手先評価 + 位置重み
- 位置重みの基本方針
  - 角: 高評価
  - 辺: やや高評価
  - 角隣接（X打ち / C打ち）: 低評価
- 評価関数例:
  - `score = 反転枚数 * a + 位置重み * b`

### 6.5 強
- ミニマックス法（深さ 3 以上推奨）
- αβ枝刈りを適用
- 評価要素
  - 石差
  - 位置重み
  - 合法手数（モビリティ）

### 6.6 最強
- ミニマックス法（深さ 5 以上推奨、終盤は読める範囲で延長）
- αβ枝刈り + 手の順序最適化（角優先など）
- 評価要素
  - 石差
  - 位置重み
  - モビリティ
  - 確定石（安定石）概念の導入（簡易版可）
- 応答時間上限の目安: 1 手 2 秒以内（超過時は深さを自動調整）

## 7. ゲーム進行仕様
1. プレイヤーが難易度・先攻後攻を選択し `対局開始`
2. 初期盤面を生成
3. 現在手番がプレイヤーの場合、入力待ち
4. プレイヤー着手後、反転・終局判定・手番交代
5. 現在手番が CPU の場合、選択難易度ロジックで着手
6. 双方の合法手がない、または盤面満杯まで 3〜5 を繰り返す
7. 終局結果を表示し、`リスタート` で再対局可能

## 8. データ構造仕様
- 盤面配列: `8x8` 二次元配列
  - `0 = 空` / `1 = 黒` / `-1 = 白`
- ゲーム状態
  - `currentPlayer`（1 or -1）
  - `difficulty`（最弱〜最強）
  - `playerColor`（1 or -1）
  - `isGameOver`（boolean）
- 補助関数
  - 合法手一覧取得
  - 指定手の反転対象取得
  - 石数カウント
  - CPU 評価計算

## 9. 操作・UX仕様
- クリック不能タイミング
  - CPU手番中
  - 終局後
- 不正クリック時の挙動
  - 盤面状態は変化させない
  - メッセージを 1〜2 秒表示
- リスタート時
  - 盤面・手番・メッセージを初期化
  - 難易度・先攻後攻は直前設定を引き継ぎ可

## 10. 非機能要件
- 盤面描画・石反転が視認しやすいこと
- 主要操作（着手、リスタート）が直感的であること
- 連続対局してもメモリリークやイベント多重登録が発生しないこと
- CPU 思考中に UI が固まりにくいこと（必要なら `setTimeout` 等で分割実行）

## 11. 受け入れ基準
- 難易度 5 段階が UI から選択でき、CPU の着手傾向が段階的に異なる
- プレイヤーが先攻 / 後攻を選択でき、選択どおりに対局が開始される
- 合法手判定、反転、パス、終局判定がルールどおりに動作する
- 終局時に石数と勝敗が正しく表示される
- `リスタート` で新規対局を問題なく開始できる

## 12. 拡張仕様（任意）
- 着手履歴（棋譜）表示
- 待った機能（1 手戻す）
- 効果音 ON/OFF
- スマートフォン向けレスポンシブ対応
