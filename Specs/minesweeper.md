# マインスイーパー仕様書

## 1. 概要
地雷を避けて全安全マスを開くマインスイーパーをブラウザで提供する。

## 2. 画面要件
- 難易度選択（Beginner/Intermediate/Expert）
- 新規ゲームボタン
- 残り地雷カウンタ（旗数ベース）
- 経過時間表示
- マス目グリッド

## 3. ゲーム仕様
- 難易度設定:
  - Beginner: 9x9, 地雷10
  - Intermediate: 16x16, 地雷40
  - Expert: 16x30, 地雷99
- 左クリック: セルを開く。
- 右クリック: 旗の ON/OFF（ブラウザのコンテキストメニューは抑止）。
- 初手では地雷を踏まないよう、最初の開示後に地雷配置する。
- 開いたセルが 0 の場合、周辺セルを連鎖的に開く。
- 地雷を開いたらゲームオーバー。
- 非地雷セルを全て開いたらクリア。

## 4. 実装要件
- 単一 HTML 内に CSS と JavaScript を同梱する。
- 再帰またはキュー探索で連鎖開示を実装。
- 盤面データ（地雷/開示/旗/隣接数）を配列管理。

## 5. 非機能要件
- 難易度変更後の再生成が即時。
- タイマーはゲーム中のみ進行。
