# マインスイーパー仕様書（改訂版）

## 1. 目的・概要
ブラウザで動作するクラシックなマインスイーパーを実装する。初手安全・難易度切り替え・レスポンシブな盤面表示を必須要件とする。

## 2. 対象環境
- 対応ブラウザ: 最新版 Chrome / Edge / Firefox（PC）
- 入力: マウス（左クリック / 右クリック）

## 3. 難易度
- Beginner: 9×9 / 地雷10
- Intermediate: 16×16 / 地雷40
- Expert: 30×16 / 地雷99

## 4. UI要件
- 難易度セレクタ
- 新規ゲームボタン
- 残り地雷カウンタ（`地雷数 - 旗数`）
- 経過時間表示
- 状態表示（準備中 / プレイ中 / クリア / ゲームオーバー）
- 盤面グリッド（セルサイズは画面サイズに応じて可変）

## 5. データモデル
各セルは以下の属性を持つ。
- `mine`: 地雷フラグ
- `open`: 開示済みフラグ
- `flag`: 旗フラグ
- `count`: 隣接地雷数（0〜8）

## 6. ゲーム進行
### 6.1 初期化
- 新規開始時に盤面を生成し、タイマーをリセットする。
- 初手まで地雷配置を遅延させる。

### 6.2 初手安全
- 最初に開いたセルは必ず非地雷。
- 実装上は周囲 8 マスも安全領域として除外可能。

### 6.3 左クリック
- 未開示かつ非旗セルを開く。
- 地雷ならゲームオーバー。
- `count=0` の場合は連鎖開示を行う。

### 6.4 右クリック
- `未設定 → 旗 → 未設定` のトグル。
- ブラウザ標準のコンテキストメニューは抑止する。

### 6.5 数字セルの周囲開示
- 開示済み数字セルに対し、周囲の旗数が数字と一致した場合、周囲未開示セルを一括開示してよい。

### 6.6 クリア条件
- 非地雷セルをすべて開示したらクリア。
- クリア時はタイマー停止。

## 7. 状態遷移
- `READY` → 初回操作で `PLAYING`
- `PLAYING` → 地雷開示で `GAME OVER`
- `PLAYING` → クリア条件達成で `CLEAR`
- 任意状態 → 新規ゲームで `READY`

## 8. 非機能要件
- Expert 盤面でも操作が著しく遅延しないこと。
- 難易度変更・新規ゲームで安定して再初期化できること。
- タイマー多重起動が発生しないこと。

## 9. 受け入れ基準
- 難易度ごとに盤面サイズと地雷数が正しい。
- 初手で地雷を踏まない。
- 連鎖開示、旗操作、クリア/敗北判定が正しく動く。
