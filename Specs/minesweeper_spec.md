# マインスイーパー仕様書

## 1. 目的・概要
本仕様は、ブラウザで動作するクラシックなマインスイーパーの実装要件を定義する。難易度選択と基本操作の再現に加え、初手救済と安定した盤面管理を重視する。

## 2. 対象環境
- 対応ブラウザ: 最新版 Chrome / Edge / Firefox（PC）
- 入力: マウス（左クリック / 右クリック）

## 3. 難易度仕様
- Beginner: 9×9, 地雷 10
- Intermediate: 16×16, 地雷 40
- Expert: 30×16, 地雷 99
- カスタム難易度は任意（実装時に UI 制約を明示）。

## 4. 画面仕様
- 難易度セレクタ
- 新規ゲームボタン
- 残り地雷カウンタ（`地雷数 - 旗数`）
- 経過時間（秒）
- 盤面グリッド
- 状態表示（PLAYING / CLEAR / GAME OVER）

## 5. 盤面データ仕様
各セルは以下の属性を持つ:
- `isMine`: 地雷か
- `isOpen`: 開示済みか
- `isFlagged`: 旗が立っているか
- `adjacentMines`: 隣接 8 マスの地雷数（0〜8）

## 6. ゲーム進行仕様
### 6.1 初期化
- 新規ゲームまたは難易度変更で盤面を再生成。
- 初手前は地雷未配置でもよい（初手安全のため）。

### 6.2 初手安全
- 最初の左クリック位置には地雷を置かない。
- 必要であれば周辺 8 マスも除外対象にして難易度を調整可（任意）。

### 6.3 左クリック
- 旗付きセルは開かない。
- 未開示・非旗セルを開示。
- 地雷セルなら `GAME OVER`。
- `adjacentMines = 0` の場合は連鎖開示を実行。

### 6.4 右クリック
- 未開示セルに対して `未設定 → 旗 → 未設定` を切り替える。
- 右クリック時にブラウザのコンテキストメニューを抑止する。

### 6.5 連鎖開示
- 0 セルを起点に隣接セルを再帰/キューで開示。
- 連鎖中、旗セルは開示対象外。

### 6.6 クリア条件
- 地雷以外のすべてのセルが開示された時点で `CLEAR`。
- クリア時はタイマー停止し、未使用地雷数表示を固定する。

## 7. タイマー・カウンタ仕様
- タイマーは最初の有効操作で開始。
- `PLAYING` 中のみ進行し、`CLEAR`/`GAME OVER` で停止。
- 残り地雷カウンタは旗の増減に同期して更新。

## 8. 状態遷移
- `READY` → 初回操作で `PLAYING`
- `PLAYING` → 地雷開示で `GAME OVER`
- `PLAYING` → クリア条件達成で `CLEAR`
- 任意状態 → 新規ゲームで `READY`

## 9. 実装要件
- 単一 HTML に CSS/JavaScript を同梱。
- 盤面管理は 2 次元配列で行う。
- 連鎖開示はスタックオーバーフロー回避のためキュー探索を推奨。

## 10. 例外・不正操作
- ゲーム終了後のセル操作は無効。
- 開示済みセルへの旗設定は無効。
- 盤面外クリックは何もしない。

## 11. 非機能要件
- Expert 盤面でも操作遅延が目立たないこと。
- 難易度変更時に 1 秒以内で盤面を再構築できること。
- 連続プレイでタイマー多重起動を起こさないこと。

## 12. 受け入れ基準
- 難易度ごとのサイズ・地雷数が正しく反映される。
- 初手で地雷を踏まない。
- 連鎖開示、ゲームオーバー、クリア判定が正しく動作する。
