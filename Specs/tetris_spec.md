# テトリス仕様書（改訂版）

## 1. 目的
ブラウザ上で動作する 1 人用テトリスを実装する。落下・回転・ライン消去・スコア管理の基本挙動を明確化する。

## 2. 対象環境
- 対応ブラウザ: 最新版 Chrome / Edge / Firefox（PC）
- 入力: キーボード（必須）、ボタン操作（補助）

## 3. ゲーム仕様
- 盤面: 10 列 × 20 行
- ミノ: I / O / T / S / Z / J / L
- 生成: 7 バッグ方式（ランダムシャッフル）

## 4. 操作仕様
- `←` / `→`: 左右移動
- `↓`: ソフトドロップ
- `↑` または `X`: 右回転
- `Z`: 左回転
- `Space`: ハードドロップ
- `P`: 一時停止 / 再開
- UI ボタン: 開始 / 一時停止 / 再開 / リスタート

## 5. ロジック仕様
### 5.1 衝突判定
- 壁・床・既存ブロックとの衝突を判定する。

### 5.2 回転
- 壁キックとして ±1, ±2 の簡易補正を試行してよい。

### 5.3 ロック
- 接地後、短いロック遅延後に固定する。

### 5.4 ライン消去
- 1〜4 ライン同時消去に対応。
- 消去後は上行を落下させる。

## 6. スコア・レベル
- ライン消去スコア: 1行=100, 2行=300, 3行=500, 4行=800
- 加算値: `基礎値 × レベル`
- レベル: 10 ラインごとに +1
- レベル上昇に応じて自然落下速度を上げる（下限設定あり）

## 7. 状態遷移
- `READY` → 開始で `PLAYING`
- `PLAYING` → 一時停止で `PAUSED`
- `PAUSED` → 再開で `PLAYING`
- `PLAYING` → 生成衝突で `GAME OVER`
- `GAME OVER` → リスタートで再初期化

## 8. 非機能要件
- 入力遅延が少ないこと。
- 連続リスタートでも動作が安定すること。
- 長時間プレイでタイマー・ループが重複しないこと。

## 9. 受け入れ基準
- 7 種ミノが正常に出現する。
- 移動/回転/落下が衝突判定と整合する。
- ライン消去、スコア、レベル、ゲームオーバー判定が正しい。
