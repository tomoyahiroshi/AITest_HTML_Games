# テトリス仕様書

## 1. 概要
10 列 x 20 行の標準的な落ち物パズルをブラウザで提供する。

## 2. 画面要件
- プレイフィールド（20x10）
- 次のミノ表示（Next）
- スコア、レベル、消去ライン数
- 操作説明
- 開始/一時停止/リスタートボタン

## 3. ゲーム仕様
- 7 種類のテトロミノ（I,O,T,S,Z,J,L）を実装。
- 操作:
  - ← → : 左右移動
  - ↓ : ソフトドロップ
  - ↑ : 回転
  - Space : ハードドロップ
- ラインが横一列埋まると消去。
- スコア計算（目安）:
  - 1ライン: +100
  - 2ライン: +300
  - 3ライン: +500
  - 4ライン: +800
- 10ライン消去ごとにレベルアップし、落下速度を上げる。
- 生成直後のミノが配置不能ならゲームオーバー。

## 4. 実装要件
- 単一 HTML 内に CSS と JavaScript を同梱する。
- `requestAnimationFrame` または `setInterval` でゲームループ。
- 回転は衝突判定を行い、壁抜けしない。

## 5. 非機能要件
- キーボード操作のレスポンス重視。
- リスタートで即時に新規プレイ可能。
