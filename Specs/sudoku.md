# 数独（Sudoku）仕様書

## 1. 概要
9x9 グリッドで 1〜9 の数字を重複なく埋める数独ゲームをブラウザで提供する。

## 2. 画面要件
- タイトル、難易度選択（Easy/Medium/Hard）、新規ゲーム、答え合わせ、リセットボタンを表示。
- 9x9 の入力グリッドを表示。
- 初期値セルは編集不可で視覚的に区別する。
- ステータスメッセージ（進行中/クリア/誤りあり）を表示。

## 3. ゲーム仕様
- 難易度に応じて空白セル数を変える。
  - Easy: 35 マス空白
  - Medium: 45 マス空白
  - Hard: 55 マス空白
- 生成済みの完全解答盤面からランダムにマスを空白化して問題を作る。
- 入力は 1〜9 のみ許容。その他は空欄扱い。
- 「答え合わせ」で以下を判定。
  - 全セルが埋まり、かつ行・列・3x3 ブロックが有効: クリア
  - ルール違反がある: エラーメッセージ表示
- 「リセット」で現在の問題を初期状態に戻す。

## 4. 実装要件
- 単一 HTML 内に CSS と JavaScript を同梱する。
- 外部ライブラリは使用しない。
- 主要ロジック:
  - バックトラッキングで解答盤面を生成
  - 行/列/ブロック重複チェック
  - 入力の正規化

## 5. 非機能要件
- PC ブラウザで快適に動作。
- 1ゲーム開始時の生成時間は体感 1 秒以内を目標。
