# ソリティア（Klondike）仕様書

## 1. 概要
1人用トランプゲーム（クロンダイク）をブラウザで提供する。

## 2. 画面要件
- 山札（Stock）/捨て札（Waste）
- 4つの組札（Foundation）
- 7列の場札（Tableau）
- 新規ゲームボタン
- ステータスメッセージ（クリア時など）

## 3. ゲーム仕様
- 52 枚の標準トランプを使用。
- 初期配置:
  - 場札 1〜7 列に 1〜7 枚配る（各列の最上段のみ表向き）。
  - 残りは山札へ。
- 山札クリックで 1 枚を捨て札へ（山札が空のときは捨て札を戻す）。
- 移動ルール:
  - 場札: 色交互、数字は降順で重ねる。
  - 空列には K を置ける。
  - 組札: 同一スートで A→K の昇順。
- 可能な場合、複数枚の場札移動を許可。
- 全組札が K まで揃うとクリア。

## 4. 実装要件
- 単一 HTML 内に CSS と JavaScript を同梱する。
- ドラッグ&ドロップ、またはクリック選択方式で移動を実装。
- 不正手は無効化し盤面を保持。

## 5. 非機能要件
- 視認性重視のカード描画。
- 新規ゲームで必ず初期化。
