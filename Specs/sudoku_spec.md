# 数独仕様書（改訂版）

## 1. 目的
9×9 の数独をブラウザで快適に遊べることを目的とする。問題生成・難易度選択・入力検証・答え合わせを提供する。

## 2. 対象環境
- 対応ブラウザ: 最新版 Chrome / Edge / Firefox（PC）
- 入力: キーボード（数字/削除）、マウス

## 3. 難易度仕様
- Easy: 空白マス少なめ
- Normal: 中程度
- Hard: 空白マス多め
- 難易度変更時は新しい問題を生成する。

## 4. 画面仕様
- 難易度選択
- 新規ゲーム
- 答え合わせ
- リセット
- 9×9 入力グリッド（3×3 ブロック境界を明確化）
- 状態メッセージ（PLAYING / ERROR / CLEAR）

## 5. データモデル
- `solution[9][9]`: 完成解
- `puzzle[9][9]`: 出題盤面（固定セル含む）
- `initial[9][9]`: 生成直後の盤面
- `fixed[9][9]`: 固定セル判定
- `state`: 現在状態

## 6. ロジック仕様
### 6.1 解生成
- バックトラック法で完全解を 1 つ生成する。

### 6.2 問題生成
- 完成解からセルを削除し、難易度に応じた空白数を作る。
- 固定セルは編集不可にする。

### 6.3 入力制御
- 可変セルのみ編集可能。
- 入力は 1〜9 のみ許可。無効入力は拒否する。

### 6.4 検証
- 行・列・3×3 ブロックで重複がないかを確認。
- 不正がある場合は `ERROR`。
- 全セル正解で `CLEAR`。

### 6.5 リセット
- `initial` を元に可変セルを初期状態へ戻す。

## 7. 状態遷移
- 新規ゲームで `PLAYING`
- 答え合わせ失敗で `ERROR`
- 答え合わせ成功で `CLEAR`
- リセットで `PLAYING`

## 8. 非機能要件
- 問題生成は体感 1 秒以内。
- 入力後の反応遅延を最小化する。
- 視認性の高い固定セル/可変セル表示。

## 9. 受け入れ基準
- 難易度変更で盤面が更新される。
- 固定セルが編集できない。
- 答え合わせで正答時に `CLEAR`、誤答時に `ERROR` を表示する。
